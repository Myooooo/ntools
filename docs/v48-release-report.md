## 2. 语义变化

- **range = 聚焦/缩放窗口**，不再是绝对过滤边界：范围内/范围外统计仍按窗口计算，但范围外任务仍渲染在画布上，向右可滚动查看（满足“滚到最晚任务”）。
- **默认 5 天窗口**：今天 00:00 起 5 天；早于今天创建的时长条默认从左缘裁剪（左缘裁剪标记），可用「扩展至全部」扩大。
- **默认隐藏完成**：时间线独立状态，列表的“显示已完成”设置不受影响。
- 无日期任务仍不显示；左侧今天/本周/逾期/已完成/清单/搜索筛选仍生效。

## 4. 已知限制

- 默认窗口从今天 00:00 起，早于今天创建的任务条左缘裁剪；需要完整时间跨度可点「扩展至全部」或手动选范围。
- 画布延伸到最晚任务：任务跨度很大（如数年后）时画布很长、滚动条很细，这是“可一直滚到最晚任务”的代价；可见任务渲染上限 600 条。
- range 现在表示聚焦窗口而非硬过滤；范围内/范围外统计仍按窗口计算，范围外任务在画布上仍可见。
- 触屏真机上的横向滚动动量/滚动条宽度仍需现场复核。
